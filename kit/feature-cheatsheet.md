【Claude Code新機能 活用早見表】

■ 機能1：自動メモリ
□ 前回までのやり取りで学んだこと・好みを、毎回説明し直していないか
□ CLAUDE.mdに「#ホットキーで書き足す」運用がまだ残っていないか
→ YES: 何もしなくてよい。関連するやり取りは自動でメモリに保存される。手動追記の指示があれば削除する
指示例: （指示不要。作業中に「これは覚えておいて」と伝えるだけで自動保存の対象になる）

■ 機能2：Artifacts参照
□ デザイン・画面仕様をスクリーンショットや文章の説明だけで渡していないか
□ 込み入った計画をmarkdown箇条書きだけで管理していないか
→ YES: HTMLアーティファクトとして作らせ、以降はそのアーティファクトを参照させる
指示例: このデザインをHTMLモックアップとしてアーティファクトに書き出して。以降の実装ではこのモックアップを参照して進めて。

■ 機能3：Deferred Tools（ToolSearch）
□ 使わないツールの定義まで毎回コンテキストに載っていて重くなっていないか
□ ツール数が多く、必要な時だけ読み込みたい場面があるか
→ YES: 普段は使わないツールを「遅延ロード」対象にし、必要な時だけToolSearchで検索させる設計にする
指示例: （ハーネス側の設定。ツール一覧に出ているが定義未取得のツールは、使う直前にToolSearchで検索してから呼び出す）

■ 機能4：send_to_userツール
□ 長時間の自律実行中に、ユーザーへ確実に見せたい内容（途中経過・部分成果物）があるか
□ ターンを終えずに「今ここまでできた」を伝えたい場面があるか
→ YES: send_to_userツールを定義し、ユーザーに見せる内容が出るたびに呼び出す指示を添える
指示例: Between tool calls, when you have content the user must read verbatim, call the send_to_user tool with that content.

■ 機能5：/doctor（CLAUDE.md・Skillの棚卸し）
□ CLAUDE.md・Skillsを一度も棚卸ししたことがないか
□ Claude Codeのバージョンがv2.1.206より古くないか（`claude --version`で確認）
→ YES: `claude update`後、`/doctor`を実行し、使用回数・推定トークンを見ながら削るものを判断する
指示例: （ターミナルでclaude Codeを起動し、対話プロンプト内で `/doctor` と入力するだけ）

■ 機能6：effortパラメータ
□ すべてのタスクを同じ設定のまま実行していないか
□ 簡単な作業でも常にhigh以上のコストをかけていないか
→ YES: タスクの難易度に応じてlow/medium/high/xhigh/maxを使い分ける
指示例: サブエージェントの単純作業はlow、通常のコーディングはhigh（既定）、30分を超える長時間タスクはxhighを検討する。
